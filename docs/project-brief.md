# Agentplace

An online platform for AI agents that answer questions, book appointments,
handle customer service, and deliver services.

## Initial foundation

- A local application development environment.
- Shared design tokens used by both the application and Storybook.
- Reusable UI components with documented variants and interaction states.
- Storybook pages for inspecting colors, typography, spacing, and components.
- Clear setup instructions and an example environment file where needed.

## Product capabilities to build next

- Agent discovery and agent detail pages.
- Conversations for questions and customer support.
- Appointment scheduling with availability and booking confirmation.
- Service requests with status tracking and delivery.

The environment includes local email/password authentication. AI integrations,
payments, scheduling providers, and a production database remain future work.
